# StickersBot

Telegram-бот для работы со стикерами, пользовательскими реакциями и административными инструментами. Проект написан на **C++20**.

> **Статус проекта:** основная функциональность реализована; дальнейшая работа сосредоточена на исправлениях, обновлениях и рефакторинге.

## Возможности

- **Каталог стикеров** — работа с записями о стикерах и просмотр каталога.
- **Навигация по каталогу** — загрузка следующих элементов без необходимости выводить весь список сразу.
- **Реакции** — возможность оценивать стикеры лайками и дизлайками.
- **Пользователи и роли** — разделение прав между обычными пользователями, модераторами и администраторами.
- **Модерация и заявки** — отдельные интерфейсы для пользовательских и административных сценариев, а также обработка заявок.
- **Рекламные инструменты** — поддержка управления рекламой и её рассылки.
- **Параллельная обработка задач** — использование пула потоков и средств синхронизации для совместного доступа к данным.

Набор доступных действий зависит от роли пользователя.

## Технологии

| Технология | Назначение |
|---|---|
| C++20 | Основной язык проекта |
| [tgbot-cpp](https://github.com/reo7sp/tgbot-cpp) | Работа с Telegram Bot API |
| Boost | Вспомогательные библиотеки C++ |
| PostgreSQL и libpqxx | Работа с реляционной базой данных |
| [nlohmann/json](https://github.com/nlohmann/json) | Обработка JSON |
| `std::thread` и средства синхронизации C++ | Параллельная обработка и безопасный доступ к общим данным |

## Требования

Для сборки и запуска понадобятся:

- компилятор с поддержкой **C++20**;
- установленная библиотека `tgbot-cpp` и её зависимости;
- Boost;
- PostgreSQL и libpqxx;
- nlohmann/json;
- Git;
- токен Telegram-бота, созданного через [@BotFather](https://t.me/BotFather).

Для разработки под Windows можно использовать Visual Studio и vcpkg. Версии библиотек и их архитектура должны совпадать с настройками проекта, например `x64`.

## Установка и запуск

### 1. Получите исходный код

```bash
git clone <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
cd StickersBot
```

Замените `<URL-ВАШЕГО-РЕПОЗИТОРИЯ>` на адрес репозитория.

### 2. Установите зависимости

Установите перечисленные выше библиотеки. Если используете vcpkg, проверьте, что Boost, libpqxx и nlohmann/json доступны проекту, а интеграция vcpkg настроена для используемого компилятора.

`tgbot-cpp` может устанавливаться отдельно — следуйте инструкции его репозитория и подключите библиотеку к проекту.

### 3. Настройте Telegram-бота и базу данных

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Настройте подключение к PostgreSQL и подготовьте необходимые таблицы согласно схеме базы данных проекта.
3. Укажите токен и параметры подключения в предусмотренном проектом конфигурационном файле или через переменные окружения — в зависимости от текущей реализации.
4. Убедитесь, что локальные файлы данных и каталоги, используемые приложением, доступны для чтения и записи.

**Не добавляйте токен, пароли или другие секреты в Git.** Для публикации репозитория используйте пример конфигурации без действующих учётных данных.

### 4. Соберите проект

Откройте файл решения или проект Visual Studio, входящий в репозиторий, и проверьте настройки:

- стандарт языка — C++20;
- архитектура и конфигурация совпадают с установленными библиотеками;
- пути к заголовочным файлам и библиотекам указаны правильно;
- при необходимости настроена связь с PostgreSQL.

Соберите проект и устраните ошибки конфигурации, если они появятся. Точный набор команд сборки зависит от build-файлов, включённых в репозиторий.

### 5. Запустите бота

Запустите собранный исполняемый файл. Перед запуском убедитесь, что PostgreSQL доступен, конфигурация заполнена, а Telegram-токен действителен.

> **Примечание:** точные параметры подключения, способ инициализации базы данных и команда сборки зависят от конфигурационных и build-файлов конкретной версии проекта.

## Хранение данных

В проекте используются PostgreSQL и JSON-файлы. В частности, каталог `Data/Storage` содержит файлы `Stickers.json` и `Users.json`.

Перед переносом установки на другой компьютер проверьте, какие данные хранятся в базе, а какие — в локальных файлах. Не удаляйте и не редактируйте эти файлы вручную без резервной копии.

## Безопасность

- Не публикуйте токен бота, пароли базы данных и другие секреты.
- Ограничивайте доступ к конфигурации и резервным копиям с пользовательскими данными.
- Перед обновлением сделайте резервные копии базы данных и локального хранилища.
- При изменении схемы базы данных проверьте совместимость изменений с уже сохранёнными данными.
